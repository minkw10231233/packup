# PackUp 이사 서비스 웹사이트

React를 사용해 제작한 반응형 이사 서비스 웹사이트입니다.  
사용자가 이사 서비스 종류를 확인하고, 상담 신청 폼을 통해 문의를 남길 수 있도록 구현했습니다.

## 주요 기능

- React Router를 활용한 페이지 이동
- 서비스 카드 컴포넌트 분리 및 데이터 기반 렌더링
- 상담 신청 폼 입력값 검증
- Fetch API를 활용한 상담 신청 POST 요청
- Loading 상태를 활용한 중복 제출 방지
- FAQ 아코디언 UI 구현
- PC / Tablet / Mobile 반응형 레이아웃 구현
- ESC 키, 외부 클릭, 닫기 버튼으로 제어 가능한 햄버거 메뉴 구현
- 접근성을 고려한 aria-label, focus 처리 적용

## 사용 기술

- React
- React Router
- JavaScript
- CSS
- Fetch API

## 페이지 구성

- `/` : 메인 페이지
- `/only-drive` : 운전만 서비스 소개
- `/one-help` : 1인 도움 서비스 소개
- `/two-help` : 2인 도움 서비스 소개
- `/consult` : 상담 신청 페이지
- `/complete` : 상담 신청 완료 페이지

## 구현 포인트

### 컴포넌트 분리

서비스 카드는 `ServiceCard`, `ServiceList` 컴포넌트로 분리했습니다.  
서비스 데이터는 `services.js`에서 관리하여, 카드 내용을 쉽게 수정할 수 있도록 구성했습니다.

### 상담 신청 폼

`useState`를 사용해 입력값과 에러 상태를 관리했습니다.  
이름, 연락처, 이메일, 상담 유형, 상담 내용에 대한 유효성 검사를 구현했고, 제출 시 Fetch API를 사용해 POST 요청을 보냅니다.  
요청 중에는 버튼을 비활성화하고 `제출 중...` 문구를 보여주어 중복 제출을 방지했습니다.

### 반응형 메뉴

햄버거 메뉴를 직접 구현했습니다.  
메뉴가 열렸을 때 ESC 키, 외부 클릭, 닫기 버튼으로 닫을 수 있도록 처리했으며, focus 이동도 함께 고려했습니다.

### 반응형 레이아웃

CSS Grid와 Flexbox를 사용해 PC, 태블릿, 모바일 환경에서 레이아웃이 자연스럽게 변경되도록 구현했습니다.

## 개선하고 싶은 점

- 반복되는 상세 페이지 구조를 공통 컴포넌트로 분리
- 실제 서버와 연동한 상담 신청 데이터 저장 기능
- TypeScript 적용
- 관리자용 상담 목록 페이지 구현
